# Current 2.0 Claim Matrix (Phase 2)

This is the current evidence matrix for the **2.0.0-alpha.1** development tree.
Historical audits and release notes are leads, not evidence; the
[audit 6 claim matrix](audit6-claim-matrix.md) records the earlier v1.9.3/1.9.4
snapshot and keeps its historical banner. This page maps the Phase 2 claims
(WP-2.1 through WP-2.13) to implementation, named tests and current operator
documentation.

Status vocabulary:

- **Delivered** — implemented on this tree and covered by the named test or
  check.
- **Delivered with residual** — the control exists, but the listed limitation is
  explicit and operator-visible.
- **Deferred** — not implemented; do not plan around it for Phase 2.

## Residuals carried forward

- Query-log anonymization is forward-only; existing rows are not rewritten.
- The `keep_aggregates` whole-range clear and the 1M-row/90-day soak remain
  capacity-testing residuals.
- HA edit-time read-only enforcement is not implemented; shared-field drift is
  detected after the write and requires a full apply.
- The release image scan is currently linux/amd64-only; live image/DNS smoke and
  root-gated HA ownership CI are Phase 3 work.
- The nightly benchmark gate is inactive until a dedicated runner baseline is
  regenerated on the same runner class.
